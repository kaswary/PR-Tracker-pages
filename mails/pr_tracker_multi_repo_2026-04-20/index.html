○ #40309: [QeRL] Add warnings for extra memory buffering [open]
背景问题或现状：当前的层级重载机制在加载权重时，如果权重加载顺序不正确，会导致内存中缓冲过多层的权重，从而引起内存使用量激增。理想情况下，权重应按层顺序加载，以避免不必要的内存占用。 目标：该 PR 旨在通过日志警告用户，当权重加载顺序不正确时，提示用户应按层顺序加载权重，以减少内存使用。 核心改动：引入了一个弱集合 `LOADING_LAYERS` 来跟踪当前正在加载的层。如果同时加载的层数超过两层，将触发警告。警告信息会包含正在加载的层的名称，以帮助用户识别问题。 使用或行为变化：当用户加载权重顺序不正确时，系统将输出警告日志，建议用户按层顺序加载权重。为了避免日志过多，警告逻辑被调整为每层只触发一次，并使用 `layer_name` 属性（如果存在）来提供更具体的层信息。 状态与特征：当前实现已通过测试，确认在从磁盘或 CPU 加载权重时不会触发警告，但在从 GPU 加载时会触发警告。预提交检查失败，需要修复后重新提交。
