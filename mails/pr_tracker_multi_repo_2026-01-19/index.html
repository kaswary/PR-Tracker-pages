该 PR 旨在解决 DeepEP 在多 GPU 环境下使用 MNNVL 时的 8-GPU 限制问题。通过引入环境变量 `DEEP_EP_NORMAL_MNNVL`，PR 使 _normal_ 模式下可以使用 MNNVL 进行跨 GPU 通信，而无需额外配置。核心改动包括移除 `use_fabric` 参数，使用 `num_nvl_ranks` 进行资源分配，并调整线程数以支持 12 和 24 GPU 配置。这些改动使得 MNNVL 在 _normal_ 模式下更灵活，但目前仍受限于特定的 GPU 数量配置。
