deepseek-ai/DeepEP

○ #557: Fix linking error with nvidia-nvshmem-cu12 3.5.19 [closed]
在升级到 NVSHMEM 3.5.19 后，DeepEP 项目遇到了多个定义链接错误，原因是 NVSHMEM 3.5.19 需要使用 `-rdc=true` 编译选项，而 DeepEP 的主机编译器（g++）无法识别该选项。为了解决这一问题，该 PR 通过在 `device_host_transport/nvshmem_common_ibgda.h` 头文件中添加 `#ifdef __CUDACC__` 守卫，确保该头文件仅在 nvcc 编译设备代码时被包含，从而避免了主机编译器错误地定义符号。这一改动消除了重复符号错误，同时保持了与 NVSHMEM 设备 API 的兼容性。当前 PR 已解决该问题，未引入新的限制或配置项。
