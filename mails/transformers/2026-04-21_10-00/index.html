○ #45541: Fix local_files_only tokenizer fallback when tokenizer files are missing (Issue 45538) [open]
该 PR 解决了在使用 `from_pretrained(..., local_files_only=True)` 时，如果缺少 tokenizer 文件，会错误地初始化一个带有巨大 `model_max_length` 的 stub tokenizer 的问题。目标是确保在这种情况下抛出 `OSError` 而不是继续初始化。核心改动是在 `PreTrainedTokenizerBase.from_pretrained` 中添加了一个检查，确保所有必要的 tokenizer 资产文件都已解析，否则抛出异常。这一改动影响了使用 `local_files_only=True` 参数加载 tokenizer 的行为，使其更加严格和可靠。当前状态是 PR 已通过本地测试，等待社区成员审查。
○ #45540: Fix cross-attention cache layer type for T5Gemma2 long inputs [open]
该 PR 解决了在 `T5Gemma2ForConditionalGeneration` 模型中，当输入长度超过滑动窗口大小（默认 4096）时生成过程中出现的 `RuntimeError`。问题的根源在于 `T5Gemma2ForConditionalGeneration._prepare_cache_for_generation` 方法中错误地删除了 `cross_attn_config` 的 `sliding_window` 和 `layer_types` 属性，导致缓存的跨注意力层在更新时截断了编码器的 K/V 状态。为了解决这个问题，PR 明确设置了 `sliding_window` 为 `None` 并将 `layer_types` 设置为全注意力层。此外，PR 添加了测试用例以验证修复效果，并确认了修复后的模型在不同输入长度下均能正常运行。
