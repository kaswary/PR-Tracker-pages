○ #45549: fix: apply channel averaging correctly in audio feature extractors [open]
该 PR 修复了多个音频特征提取器中通道平均计算的错误。错误导致批处理张量输入在最后一个维度上进行平均而不是在通道维度上，以及批处理序列输入的平均结果未正确写回 raw_speech。此更改通过在通道维度上使用 mean(1) 并将单声道转换后的样本写回 raw_speech 来解决这些问题。这些修复不会改变现有 API 的使用方式，但会确保输出的正确性。当前状态为等待指定的测试任务运行。
○ #45548: Fix EP + DeepSpeed ZeRO-3 loading via accelerate launch [open]
在使用 Expert Parallelism (EP) 和 DeepSpeed ZeRO-3 时，通过 `accelerate launch` 加载模型会因为两者初始化方式的冲突而挂起。该 PR 的目标是解决这一问题，使 EP 和 ZeRO-3 能够兼容工作。核心改动包括在 `from_pretrained` 中为 EP+DS 路径使用标准的非 ZeRO-3 初始化方式，确保 EP 的 sharding hooks 正常工作，并在模型加载后通过 `deepspeed.initialize()` 包装模型。这些改动确保了模型在 EP 和 ZeRO-3 共存时能够正确加载和初始化。当前状态是通过测试验证了该 PR 的有效性，但需要进一步的审查和确认。
