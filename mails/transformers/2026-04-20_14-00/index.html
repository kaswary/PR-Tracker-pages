○ #45524: utils: handle flash_attn missing from importlib packages_distributions without crashing [open]
在某些环境中，如 Python 3.13 和 ComfyUI 设备上，`flash_attn` 包的导入检查会因 `packages_distributions()` 中缺少相应键而引发 `KeyError`，导致整个导入过程失败。该 PR 的目标是修复这一问题，确保在 `flash_attn` 包未正确安装时不会引发异常。核心改动是将四个引发异常的字典访问替换为 `.get(name, [])`，从而避免 `KeyError`。这一改动不会影响现有行为，仅在 `flash_attn` 包未正确安装时返回 `False`。当前状态良好，无需额外配置或回退机制。
○ #45523: Fix Seq2SeqLM ExecuTorch export: add encoder_attention_mask to decoder and use static encoder shapes [open]
该 PR 解决了 `src/transformers/integrations/executorch.py` 中的两个 bug，这些 bug 导致 T5 模型在 ExecuTorch 导出时无法正确运行。第一个 bug 是 `encoder_attention_mask` 未传递给解码器，导致输出错误。第二个 bug 是动态编码器维度与静态 KV 缓存冲突，导致运行时错误。为了解决这些问题，PR 修改了相关模块的前向传播方法，添加了 `encoder_attention_mask` 参数，并去除了动态编码器维度。这些改动确保了 T5 模型在 ExecuTorch 导出后的输出与 HuggingFace `model.generate()` 完全一致。当前状态包括对自定义 T5 检查点的验证，以及对现有测试的扩展。
