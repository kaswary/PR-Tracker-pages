○ #406: fix(fuse): fix double-reply and null-deref in iovs/addIoRing error path [open]
在 FUSE `symlink` 处理器中，当 `addIoRing` 失败时，代码会将 `addIoRing` 的结果传递给 `handle_error` 并立即返回，以确保客户端收到正确的错误信息并避免双重回复。此 PR 的目标是修复错误路径，确保在 `addIoRing` 失败后不会发送第二个 FUSE 回复，从而避免不安全的后续逻辑。核心改动包括将 `addIoRing` 的结果传递给 `handle_error` 并立即返回，同时在 `addIoRing` 失败时回滚 `addIov` 的成功操作，以防止资源泄漏。这些改动确保了系统状态与返回给客户端的错误信息一致。
